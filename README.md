# Week 5 Lab - Data Wrangling with `dplyr`

## Goal

Practice using `dplyr` to filter and arrange rows, select columns, create new variables, summarize grouped data, and join related data frames.

## Complete the Lab

1. Open `Week_05_Lab_Data_Wrangling.R` in RStudio.
2. Load the required packages in the Package Setup section.
3. Complete each `TODO` in order and use the object names provided.
4. Run the entire script from a clean R session and confirm that it works without errors.

If a package is missing, install it from the Console. Do not include `install.packages()` in your submitted script.

## Submit

Save the script, commit and push your changes, and verify the completed file on GitHub. Submit the repository URL in Blackboard, not a link to an individual file.
